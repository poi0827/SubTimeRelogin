# SubTimeRelogin

FF14 国服（卫月 / Dalamud CN）插件：记录点卡与月卡剩余时间，月卡未到期时掉线自动重连。

## 功能

- 登录后在角色选择界面读取国服客户端的月卡 / 点卡剩余时间并保存。
- 服务器信息栏（DTR）常驻显示月卡剩余时间，悬浮查询月卡 / 点卡详情，右键打开设置窗口。
- 角色选择界面覆盖显示「月卡：…／点卡：…」。
- 掉线（90002）后，若月卡仍有剩余时间，持续尝试自动登录并选中上次登录的角色。
- 可选：清除登录锁、自动确认 `Dialogue` 提示框。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/sublogin` | 打开设置窗口 |
| `/sublogin record` | 立即读取一次订阅时间 |
